# E1–E3 对照实验结果（2026-09-30）

这是历史批次的结果摘要。逐条原始输出和复核底表未随源码上传；本轮之后的规划器修复也不改变这些已记录的历史统计。若需独立复核数值，应另取原始数据快照。

本轮执行了 E1、E2、E3；按要求未执行 E4。冻结数据为 10 篇论文、50 道 QA、10 个 Research Goal 和 8 个连续研究场景。正式批次均使用智谱 `glm-4-flash`、温度 0；E1 的 `top_k=8`。最初拟用 DeepSeek 的批次因 HTTP 402 额度不足而标记为 `invalid_interrupted`，不与本轮结果合并，也不作为对照组。原始运行目录中的 `manifest.json` 记录模型、数据哈希和配置。

## E1：证据链消融

50 道问题 × 4 变体，共 200 条回答；四组各 50 条，运行错误均为 0。10 道论文范围陷阱题中，全库检索的 `VANILLA_RAG` 有 7/10 **检索结果**包含未选论文；另外三组均为 0/10。这项指标只说明检索范围，不能当成最终答案越界率。

10 道证据不足题中，独立 Evidence Decision 在 `SCOPE_EVIDENCE` 与 `PAPERAGENT_FULL` 各明确做出 9/10 次 `ABSTAIN` 决定；两组基础变体无独立判定层，因而是 0/10。但四组共用的回答提示词均要求在证据不足时拒答；逐条查看这 40 个最终回答后，四组都没有编造题目所要求的具体数值，并均表达了无法依据证据回答。因此，**本轮不能据 9/10 对 0/10 宣称最终拒答表现获得提升**。

原始执行时只保存检索文档和页码，事后重放索引以补充逐条证据文本。近似向量检索的重放顺序在 19/200 条上与原始记录不同；这些记录不能用于精确的主张支持率或引用准确率核查。可精确匹配的为 181/200：`VANILLA_RAG` 34/50，其余三组各 49/50。评分尚未完成独立的第二人复核，待审底表见 `metrics/e1_review.csv`。`PAPERAGENT_FULL` 的 Grounding 验证仅记录状态，不会改写回答，不能由此推断它改善了答案质量。

### 181 条精确证据样本的单人初审

另对可精确匹配的 181 条记录做了单人快速审阅，逐行标签与计算脚本保存在 `metrics/partial_e1_review_rows.csv`、`metrics/partial_e1_review.json` 和 `score_partial_e1.py`。这些数字尚未经过第二位审阅者独立复核，**不能与上面的机器指标或历史正式评测混写为最终定稿结果**。

| 指标 | 单人初审结果 | 分母口径 |
| --- | ---: | --- |
| Answer Correctness | 150/181（82.9%） | 以冻结标准答案判断核心事实；含 35 条证据不足题的正确拒答 |
| Claim Support Rate | 121/146（82.9%） | 仅 146 条可回答题，逐回答给 0、0.5、1 分后取均值 |
| Final Answer Leakage | 0/36；Full 组 0/10 | 只在 Scope 题判断最终回答是否用了未选论文的信息 |
| Citation Accuracy | 28/31（90.3%） | Full 组有引用的可回答题，判断引用页是否支持核心回答 |

冻结标准答案 Q003 写“三项”，论文正文的 Results 节却写“四项”（仅 TQA 可比划分）；四个变体均回答“四项”。如采用论文正文对此题判对，Answer Correctness 变为 **154/181**。引用准确性按是否支持**实际回答**判断，Q003 的正文引用可支持“四项”，因此不把它算作错误引用。28/31 的三个未通过项为 Q010（出现不存在的 `[C9]`）、Q017（SWaT 被误称为 Server Machine Dataset）、Q018（引用页并未支持所问的 18.76% 比较）。引用编号可解析率为 Full 组 75/76，这只检查编号，不能替代 28/31 的语义引用准确性。

## E2：研究规划消融

10 个目标 × 2 变体 × 2 次，共 40 条；两组各 20 条，运行级错误均为 0。

| 指标 | 开放规划器 | PaperAgent 受控规划器 |
| --- | ---: | ---: |
| 计划合法 | 8/20（40%） | 20/20（100%） |
| 计划含未注册 Skill | 12/20（60%） | 0/20（0%） |
| 最低规则下任务成功 | 6/20（30%） | 12/20（60%） |

“最低规则成功”仅要求计划合法、步骤完成、生成预期类型的产物，并未检查报告内容正确性。受控规划器仍失败 8/20：R05 把多个文档 ID 作为列表传给只接受单个字符串的 `PaperReaderInput.document_id`；R08、R09 出现读错或不存在的文档 ID；R06 未满足最低产物规则。这暴露了计划合法性检查尚未覆盖 Skill 输入模式及文档存在性。最低内容要求与 Artifact 事实溯源待 `metrics/e2_review.csv` 人工核验。

## E3：连续研究工作空间

8 个场景 × 独立会话、PaperAgent 工作空间，共 16 条，运行级错误 0。经实际 Ask/Research API 执行，最低工作流完成为独立会话 1/8（12.5%）、工作空间 7/8（87.5%）。这是 **API 返回与产物存在的最低规则**，尚不是答案或研究报告质量评分。S04 为反例：独立会话成功，工作空间失败；失败的续研计划引用了不存在的 `previous_comparison` 依赖。

工作空间条件在 8/8 条中保留了父任务 ID；前轮有产物且后轮具有父任务链接也为 8/8。这只证明结构关联，**不证明后轮实际使用了前轮产物内容**。当前 Ask 中选定的论文范围在进入 Research 时，两组均为 0/8 自动继承；测试遵循现有前端发送 `document_ids=[]` 的行为，并在研究目标文字中显式附上本地文档 ID。工作空间组脚本设定的重复输入操作数平均 1 次，独立会话组 4 次；这不是用户实测时间或操作量。答案内容连续性仍需人工复核。

## 解释范围与复现

- 三组均保留全部正式样本和失败记录，没有丢弃 S04 等反例。
- E1 的“Vanilla”是无代码级论文范围限制和独立 Evidence Decision 的检索生成对照；四组共享产品回答提示词，其中已有证据不足时拒答的要求。
- E2 的合法性统计由实验审查器计算，条件略严于当前产品 Planner 的静态校验；两组使用相同 Executor。
- E3 的任务完成差异包含规划器与外部工具波动，不能单独归因为“长期记忆”或“信息保真”。研究工具在个别步骤仍使用了外部检索，即使目标文字要求只读本地论文。
- 原始记录、自动摘要、待审表与重现命令见本目录 `README.md`。机器摘要为 `metrics/objective_summary.json`。未完成的人工作业指标保持 `pending_human_review`，不得写成 0 或 100%。

在技术报告中可陈述本轮对**范围约束、规划合法性和工作流关联**的观察结果；若要报告答案正确率、引用准确率、产物事实质量或真实用户效率，必须先完成相应人工审核或用户试验。
