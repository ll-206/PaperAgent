## 2. 仍需人工验收的业务链路

| 场景 | 当前状态 | 建议操作 |
|---|---|---|
| 新 PDF 上传 → Worker 索引 → PDF 渲染 → 单/多论文问答 → 引用跳页 | 未在本轮真实端到端执行 | 用专门的测试知识库和有授权的测试 PDF 完成一遍，核对页码与回答证据 |
| DeepSeek/Kimi/GLM 真实生成和模型切换 | 本轮未调用云端模型 | 在服务器上用少量测试问题检查 API 配额、流式事件、超时与模型切换 |
| 外部 arXiv/OpenAlex 检索及 arXiv PDF 导入 | 自动化覆盖意图/边界，真实外网未验收 | 用公开论文和服务器实际网络验证结果及导入 |
| Research 完整目标到 Artifact、失败重试和跨轮继续 | 自动化覆盖部分持久化/延续，真实长任务未运行 | 用可控研究目标测试状态、耗时、来源和重启行为 |
| 浏览器交互细节 | 未逐尺寸人工走查 | 检查阅读器拖拽、PDF 缩放、选区翻译、笔记编辑、问答窗、历史侧栏及窄屏 |
| Linux 新服务器安装 | 未在本轮执行 | 按部署文档在目标环境安装，并记录依赖、模型和 Nginx 验收结果 |

## 3. 已知限制与处理

1. 论坛后端接口存在，但当前前端论坛路由被注释，网页端不可访问。软件功能说明按当前可见版本记录。
2. 当前 `vue-tsc@1.8.27` 搭配本机安装的 `typescript@5.6.2`、Node.js 24.14.0 时，`npx vue-tsc --noEmit -p tsconfig.web.json` 在工具内部报 `Search string not found`。这是类型检查工具兼容性问题；生产 Vite 构建成功。本轮未把类型检查写成通过。
3. `/health/ready` 的云端模型字段表示已配置，不主动发真实 API 请求；真实模型调用仍需单独验收。
4. 研究任务在 API 进程内执行，进程重启可能使运行中的任务停滞；尚未实现跨进程恢复队列。
5. 文档说明的是可重建的源代码与依赖。生产 `.env`、数据库、论文原件、下载的 BGE 模型和 Chroma 索引不应进入公开 Git 仓库；它们需单独部署、备份与分发。
