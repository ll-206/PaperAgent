# PaperAgent 软件功能说明

更新日期：2026-09-30。本说明按当前前端路由和后端接口编写。功能可见性会受账号角色、模型配置、PDF 索引状态和网络连接影响；测试结论见 [功能验证记录](功能验证记录.md)。

## 1. 产品定位与角色

PaperAgent 是论文阅读与研究工作台，围绕“收集 PDF → 建立知识库 → 阅读/笔记 → 有证据的问答 → 延续研究”组织功能。普通账号管理自己的资料；加入团队后使用团队共享工作空间。管理员还可审批团队成员和修改团队名称。前端使用 JWT 登录状态访问后端，业务记录按工作空间 `lid` 隔离。

## 2. 页面与能力总览

| 页面 | 入口 | 当前能力 |
|---|---|---|
| 登录/注册 | `/login` | 密码登录；注册时可填团队名提交加入申请；注册后等待管理员审批 |
| 今日概览 | `/home/dashboard` | 今日问答、研究、上传、阅读时长统计；研究目标、帖子摘要、论文及笔记入口 |
| 论文库 | `/home/library` | 知识库创建、搜索、编辑、删除；论文列表、上传、阅读、删除；笔记集入口 |
| 论文阅读器 | `/home/pdfInfo/:knowledgeID/:documentID` | PDF 翻页、按钮及 Ctrl+滚轮缩放、选中内容翻译、论文问答、分栏拖拽 |
| 笔记集 | `/home/library/notes` | 按知识库归集非空笔记、搜索、打开对应论文、确认后删除笔记 |
| 全屏笔记 | `/home/note/fullscreen/:knowledgeID/:documentID` | 左侧论文、右侧富文本/Markdown 笔记编辑 |
| 智能问答 | `/home/Chat` | 普通对话、单/多论文上下文选择、临时上传、对话历史、模型选择、研究模式入口 |
| 深度研究 | `/home/research` | 创建研究任务、历史任务、进度、步骤与交付物、从结果继续下一轮 |
| 管理团队 | `/home/team` | 管理员查看团队、重命名、审批加入申请、查看或移除成员 |

论坛服务端仍有帖子与评论接口，概览也可显示帖子摘要，但当前前端路由已隐藏论坛页面，因此**不能将论坛发布/浏览算作本版网页端已开放功能**。

## 3. 详细功能

### 3.1 账号、团队与共享范围

- 注册要求用户名为 3–50 位字母、数字、下划线或连字符；密码长度为 8–128 位。注册时团队名可不填。
- 填写团队名时，新团队名或管理员用户名可用于定位团队；匹配后产生待审批申请。若名称不唯一，系统不会猜测目标团队。
- 管理员通过申请后，成员可使用团队知识库与对话；被移除后回到个人空间。
- 管理员可以在“团队信息”中重命名，名称不能空、不能超过 50 字符，也不能与其他团队名称/管理员用户名冲突。团队 ID 和已有成员关系不会因改名改变。
- API 端负责鉴权和资料归属校验；前端是否显示入口仅是交互层控制，不代替服务端权限。

### 3.2 今日概览

概览按当前工作空间和本地日期聚合：知识库、文档与向量数量；当天智能问答次数、研究任务数、上传篇数、阅读分钟数；研究方向及状态；本人和近期帖子摘要；上传论文所属知识库与标签；已阅读论文的时长及是否有笔记。用户可从概览跳转对应研究、论文或笔记。阅读时长由打开的论文页面在可见且获得焦点时定时上报，属于使用时长估算，不是精确阅读质量指标。

### 3.3 论文库与文档处理

用户可创建知识库、填写描述、搜索及筛选，修改名称/描述，批量删除知识库。每个知识库下可上传 PDF、查看文档状态与标签、阅读或删除。上传时以内容 MD5 作为文档标识，同一知识库重复上传同内容会返回冲突。上传成功表示文件已保存并排队；独立 Worker 随后解析 PDF、切分、生成摘要与标签、建立 Chroma 向量索引，处理完成后状态才变为就绪。可从外部学术搜索结果选择符合条件的 arXiv PDF 导入；非直接可导入的结果需先手工下载再上传。

### 3.4 阅读、翻译和笔记

阅读器左右分栏，左侧 PDF，右侧上下可调的翻译/笔记与论文问答。用户可拖动边界调整空间；PDF 支持前后翻页、缩放按钮与 Ctrl+滚轮，缩放范围 50%–250%，内容在 PDF 区域内滚动。选中英文后调用**本地离线英中模型**，不经云端翻译 API；一次最多 12000 字符，长段落会分块翻译。首次部署需安装离线语言包。

笔记与知识库、论文及工作空间绑定；阅读页可编辑并保存，笔记集只显示非空笔记。笔记集按知识库组织，支持关键词搜索、打开对应论文和笔记，以及二次确认后删除笔记；删笔记不删除论文文件。全屏笔记页提供更宽的编辑区域。

### 3.5 智能问答与论文助手

用户可进行一般问答、绑定一篇或多篇论文问答、上传临时 PDF，也可从 Library 选择文档。已选论文的 ID 随问题提交；后端先校验该工作空间是否有权访问这些文档，然后限定检索范围。针对所选论文的提问会检索论文片段，使用证据判断与反幻觉核验，响应中可带 `[C#]` 引用及页码以便回查。无足够证据时说明不足，不应杜撰精确事实。非论文通用问题走一般聊天路径；论文推荐/跨领域研究类请求可以触发外部学术搜索，结果质量取决于外部服务可用性。

智能问答使用 SSE 逐段呈现回答，并显示思考/回答耗时；历史会话可回看，侧栏宽度可调。可选模型以实际服务器配置为准：DeepSeek 必需，Kimi 与智谱 GLM 为可选；切换模型不改变资料访问权限。论文阅读页中的“论文问答”围绕当前文档提问，跟主智能问答的资料选择方式不同。

### 3.6 深度研究

输入研究目标后，后端创建持久化任务，返回任务 ID；后台编排器生成步骤，调用注册的研究技能，记录步骤状态与耗时，并保存研究交付物。界面显示任务总数、成功数、需关注数、当前交付物，以及可收起的历史任务；选中任务可查看计划、步骤、错误和交付物。可从既有任务的结果继续下一轮研究，后一轮保留父任务 ID 和部分前轮结果摘要。

研究能力依赖当前可用论文、外部学术来源与云端 LLM。状态可能是待执行、运行、完成或失败；失败任务保留错误信息，不能视为已完成结果。研究启动时只接受属于当前工作空间的论文 ID，任务和成果也按工作空间读取。

## 4. 使用边界

1. 大模型回答、外部搜索和研究建议需要人工核对论文原文；引文链接是核查入口，不是对所有结论的自动事实保证。
2. `/health/ready` 只证明本地依赖与密钥配置就绪，不验证云端服务此刻可连接。
3. 临时 PDF 与长期入库 PDF 的保存方式不同；团队成员需要明确当前对话实际选中的论文范围。
4. 后台研究在 API 进程内执行，进程重启可能中断正在运行的任务；目前不是跨机器队列系统。
5. 论坛网页入口当前未开放，相关后端接口属于保留能力。
