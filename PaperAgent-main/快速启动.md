# PaperAgent 快速启动说明（组员版）

> 拿到压缩包后，按下面三步配置环境，之后双击 `start_all.ps1` 即可一键启动。
> 系统要求：Windows 10/11，建议 16GB 内存、预留 15GB 磁盘空间。

---

## 〇、压缩包应该包含什么

组长打包时，请确保包含以下内容；组员拿到后检查目录结构是否完整。

```
PaperAgent/
├─ start_all.ps1              # 一键启动脚本（双击/右键运行）
├─ 快速启动.md                # 本说明
├─ PaperQuery_Backend/        # 后端
│  ├─ main.py                 # 后端 API（端口 8001）
│  ├─ vector.py               # 向量化 Worker（处理上传文档）
│  ├─ requirement.txt         # 后端依赖清单
│  ├─ .env                    # 环境配置（含 API Key、密钥）
│  ├─ models/                 # BGE-M3 + Reranker 模型（约 5.6GB，必须带）
│  │  ├─ bge-m3/
│  │  └─ bge-reranker-v2-m3/
│  └─ res/                    # 数据库 / 向量索引 / 已上传 PDF
└─ PaperQuery_Frontend/       # 前端
   ├─ package.json
   ├─ package-lock.json
   ├─ config/                 # 环境变量（含后端地址）
   └─ src/
```

### 打包时【务必排除】以下目录/文件

| 排除项 | 原因 |
|--------|------|
| `PaperQuery_Backend/.venv/` | conda 环境绑定了绝对路径，换机器会失效，需组员本地重建 |
| `PaperQuery_Backend/.conda_pkgs/` | conda 安装缓存，约 330MB，无用 |
| `PaperQuery_Frontend/node_modules/` | 前端依赖约 600MB，组员 `npm install` 重建 |
| `**/__pycache__/`、`.pyc_cache/` | Python 编译缓存 |
| `PaperQuery_Backend/_faulthandler_dump.txt`、`tmp.txt` | 调试残留 |

> ⚠️ **安全提示**：`PaperQuery_Backend/.env` 内含 DeepSeek API Key 与 JWT 密钥。
> 若不希望密钥外泄，可删除 `.env` 里的 `DEEPSEEK_API_KEY`，让组员自行填入。

## 一、安装 Node.js（前端依赖）

前端用 Vite 构建，需要 Node.js 18 及以上（推荐 20/22）。

1. 下载安装：https://nodejs.org（选 LTS 版，一路默认下一步）。
2. 安装完成后，打开 **PowerShell**，验证：
   ```powershell
   node -v
   npm -v
   ```
   能打印版本号即成功。

---

## 二、安装后端 Python 环境

后端要求 **Python 3.12**。

1. 安装 Python 3.12（勾选 "Add to PATH"）：https://www.python.org/downloads/release/python-3120/

2. 在 `PaperQuery_Backend` 目录下创建虚拟环境并安装依赖：
   ```powershell
   cd PaperQuery_Backend
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install --upgrade pip
   .\.venv\Scripts\python.exe -m pip install -r requirement.txt
   ```

   > 首次安装会下载 torch（约 2GB）+ FlagEmbedding 等，耗时较长，请耐心等待并保证网络通畅。

3. 确认 `.env` 文件存在（内含 `DEEPSEEK_API_KEY`、`SECRET_KEY` 等）。若缺失，复制 `.env.example` 改名为 `.env` 并填入真实 Key。

### 附：模型下载（仅当压缩包内没有 `models/` 时）

若组长打包时未附带 `models/`（约 5.6GB），请手动下载 BGE-M3 与 bge-reranker-v2-m3
到 `PaperQuery_Backend/models/` 下：

```powershell
cd PaperQuery_Backend
.\.venv\Scripts\python.exe -m pip install -U huggingface_hub

# 国内可先设置镜像，再执行下载
$env:HF_ENDPOINT = "https://hf-mirror.com"

.\.venv\Scripts\python.exe -m huggingface_hub download BAAI/bge-m3 --local-dir models/bge-m3
.\.venv\Scripts\python.exe -m huggingface_hub download BAAI/bge-reranker-v2-m3 --local-dir models/bge-reranker-v2-m3
```

> 若缺少模型，系统会自动降级为基础检索（功能仍可用，但未启用混合检索/重排）。

## 三、安装前端依赖

在 `PaperQuery_Frontend` 目录执行：

```powershell
cd PaperQuery_Frontend
npm install
```

> 若安装缓慢，可先切换国内镜像：
> ```powershell
> npm config set registry https://registry.npmmirror.com
> ```

## 四、一键启动

双击 `start_all.ps1`，或右键选择「使用 PowerShell 运行」。

脚本会依次启动：
- 后端 API（`http://127.0.0.1:8001`）
- 向量化 Worker（`vector.py`，处理上传的文档）
- 前端页面（`http://127.0.0.1:8080`）

启动成功后，浏览器访问：

```
http://127.0.0.1:8080
账号：admin
密码：123456
```

> 首次启动后端需要加载 BGE-M3 / Reranker 模型，约 10~20 秒后才能正常响应；
> 若页面数据没加载出来，稍等片刻刷新即可。

## 五、常见问题（FAQ）

| 现象 | 原因 / 解决 |
|------|------------|
| 脚本提示「后端 Python 环境 .venv\python.exe 缺失」 | 未完成第二步，请先在 `PaperQuery_Backend` 执行 `python -m venv .venv` 并装依赖 |
| 脚本提示「前端依赖 node_modules 缺失」 | 未完成第三步，请先在 `PaperQuery_Frontend` 执行 `npm install` |
| 脚本提示「Node.js 缺失」 | 未安装 Node，见第一步 |
| 页面一直显示加载骨架（Dashboard/Library） | 后端未启动或还在加载模型，检查 8001 端口是否监听，或等待后刷新 |
| 上传文档后一直「处理中」 | 向量化 Worker 未运行，确认 `vector.py` 进程存在（可用脚本重新启动） |
| 登录失败 / Token 过期 | 确认后端 8001 正常，`.env` 中 `SECRET_KEY` 与 `ALGORITHM` 未改动 |
| 检索/问答结果为空 | 模型目录 `models/` 未随压缩包一起提供，或文档未完成向量化 |

## 六、手动启动（不使用脚本时）

分别打开三个终端：

```powershell
# 终端 1：后端 API
cd PaperQuery_Backend
.\.venv\Scripts\python.exe main.py

# 终端 2：向量化 Worker
cd PaperQuery_Backend
.\.venv\Scripts\python.exe vector.py

# 终端 3：前端
cd PaperQuery_Frontend
npm run dev
```
